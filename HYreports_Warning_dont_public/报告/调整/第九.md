### 1. 人脸识别签到流程实现

- **签到接口设计**  
  学生端通过前端拍照上传签到照片，后端接收图片后，调用人脸识别算法进行身份校验。接口支持图片的接收、存储、格式校验，并与学生人脸库进行比对，判断签到是否有效。

- **图片处理与安全校验**  
  上传图片时，后端会校验图片格式和大小，防止恶意文件上传。图片保存采用唯一命名（如`studentid_taskid_timestamp.jpg`），并存储在专用目录下，便于后续审核和追溯。

- **人脸识别算法调用**  
  后端集成了人脸识别模块（如调用第三方API或本地模型），对上传图片与学生预留人脸数据进行比对。比对成功则签到成功，否则记录为异常签到，需后续人工审核。

- **代码片段说明**  
  ```python
  @student_attendance_bp.route('/sign', methods=['POST'])
  @jwt_required()
  def student_sign():
      user_id = int(get_jwt_identity())
      task_id = request.form.get('taskId')
      image_file = request.files.get('faceImage')
      # 校验图片格式
      if not allowed_file(image_file.filename):
          return Result.error('图片格式不支持')
      # 保存图片
      filename = f"{user_id}_{task_id}_{int(time.time())}.jpg"
      save_path = os.path.join(current_app.config['UPLOAD_FOLDER'], 'attendance', filename)
      image_file.save(save_path)
      # 人脸识别比对
      is_match = face_recognition_api.compare(user_id, save_path)
      if is_match:
          status = '正常'
      else:
          status = '异常'
      # 记录签到
      record = AttendanceRecord(
          task_id=task_id,
          student_id=user_id,
          status=status,
          sign_time=datetime.now(),
          face_image=filename
      )
      db.session.add(record)
      db.session.commit()
      return Result.success(message='签到完成', data={'status': status})
  ```
  该流程实现了图片校验、存储、人脸比对和签到记录的完整闭环。

### 2. 异常签到申诉与教师审核

- **异常签到申诉**  
  学生如遇人脸识别失败或特殊情况，可在前端发起申诉，上传补充材料（如请假条、说明图片等）。后端记录申诉信息，等待教师审核。

- **教师审核接口**  
  教师端可查看所有异常签到和申诉记录，支持审核通过或驳回。审核通过后，签到状态可由“异常”变为“正常”或“请假”等。

- **代码片段说明**  
  ```python
  @teacher_attendance_bp.route('/review', methods=['POST'])
  @jwt_required()
  def review_sign():
      data = request.get_json()
      record_id = data.get('recordId')
      new_status = data.get('status')  # '正常'、'请假'、'驳回'
      record = AttendanceRecord.query.get(record_id)
      if not record:
          return Result.error('签到记录不存在')
      record.status = new_status
      db.session.commit()
      return Result.success(message='审核完成')
  ```
  该接口实现了教师对异常签到的人工审核和状态变更。

### 3. 教师端签到统计与数据展示

- **签到统计接口**  
  教师端可按课程、签到任务等维度，统计学生出勤、缺勤、请假等数据，支持分页、筛选和导出。

- **数据展示与分析**  
  后端接口返回统计数据，前端可直观展示出勤率、异常率等，辅助教师管理班级考勤。

- **代码片段说明**  
  ```python
  @teacher_attendance_bp.route('/stats', methods=['GET'])
  @jwt_required()
  def attendance_stats():
      course_id = request.args.get('courseId')
      task_id = request.args.get('taskId')
      # 查询统计
      total = AttendanceRecord.query.filter_by(task_id=task_id).count()
      normal = AttendanceRecord.query.filter_by(task_id=task_id, status='正常').count()
      abnormal = AttendanceRecord.query.filter_by(task_id=task_id, status='异常').count()
      return Result.success(data={
          'total': total,
          'normal': normal,
          'abnormal': abnormal,
          'rate': f"{normal}/{total}"
      })
  ```
