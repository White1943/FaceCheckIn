本周主要聚焦于“文件上传接口设计与安全实践”。文件上传是后端系统中与用户体验和安全密切相关的部分，涉及接口设计、文件类型校验、存储路径管理、异常处理等多个细节。本周我实现了头像上传接口，并对文件上传的安全性、异常处理等方面进行了深入实践和优化。

具体进展如下：

1. **文件上传接口设计**
   - 在 `app/auth/views.py` 中设计了用户头像上传接口，采用 POST 方法，接收前端通过 multipart/form-data 上传的图片文件。
   - 通过 Flask 的 `request.files` 获取文件对象，并进行一系列校验，包括文件类型、文件大小、文件名安全等。

2. **文件类型与大小校验**
   - 只允许上传 jpg、jpeg、png 等图片格式，防止恶意文件上传。
   - 通过配置 `MAX_CONTENT_LENGTH`，限制单个文件最大为 5MB，防止大文件占用服务器资源。

3. **文件名安全处理**
   - 使用 `werkzeug.utils.secure_filename` 对文件名进行安全处理，防止路径穿越攻击。
   - 采用 user_id + 时间戳 生成唯一文件名，防止文件名冲突和覆盖。

4. **接口安全与异常处理**
   - 通过 @jwt_required() 装饰器确保只有已登录用户可以上传头像。
   - 对文件保存、数据库更新等关键步骤增加 try-except，出现异常时及时回滚并返回明确的错误信息。
