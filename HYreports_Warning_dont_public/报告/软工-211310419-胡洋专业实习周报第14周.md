## 一、课题进展情况

本周的主要任务是"数据模型设计与ORM优化"。随着系统功能的不断丰富，后端数据模型的合理设计和ORM（对象关系映射）技术的高效应用，成为保障系统性能、数据一致性和开发效率的关键。本周我对项目中的核心数据表结构、字段设计、关系映射、ORM高级用法等进行了系统梳理和优化，并总结了开发过程中遇到的典型问题与解决方案。

具体进展如下：

1. **核心数据模型设计梳理**  
   - **用户表（User）**：设计时充分考虑了用户身份的多样性（教师、学生、管理员），采用枚举类型区分角色，字段包括用户名、密码哈希、真实姓名、邮箱、状态、头像等，满足后续权限控制和个性化展示需求。
   - **课程表（Course）**：包含课程名称、所属教师、学期、描述、上课时间、地点等字段，支持课程的全生命周期管理。通过外键与教师用户建立一对多关系。
   - **课程学生关联表（CourseStudents）**：实现学生与课程的多对多关系，采用联合主键（course_id, student_id）防止重复选课，并记录选课时间，便于后续统计和管理。
   - **签到任务表（AttendanceTask）**：关联课程和教师，记录签到任务的起止时间、地点、状态等，支持灵活的考勤管理。
   - **签到记录表（AttendanceRecord）**：关联签到任务和学生，记录签到时间、状态、图片等，支持考勤统计和异常申诉。

2. **字段选择与约束设计**  
   - 所有主键均采用自增整数，保证唯一性和查询效率。
   - 关键外键字段均加上`nullable=False`，确保数据完整性。
   - 通过`db.Enum`、`db.String`、`db.DateTime`等类型，合理约束字段取值和格式。
   - 对于多对多关联表，采用`db.UniqueConstraint`实现联合唯一约束，防止重复数据。
   - 重要字段（如用户名、课程名）加上唯一索引，提升查询效率并防止重复。

3. **ORM关系映射与高级用法**  
   - **一对多关系**：如教师与课程，用户模型中通过`teaching_courses = db.relationship('Course', back_populates='teacher')`实现，课程模型中通过`teacher = db.relationship('User', back_populates='teaching_courses')`反向关联。
   - **多对多关系**：如学生与课程，通过中间表`course_students`和`secondary`参数实现，支持链式查询和动态加载。
   - **懒加载（lazy）**：对大数据量的关联关系，采用`lazy='dynamic'`，避免一次性加载全部数据，提升性能。例如`user.enrolled_courses`、`course.students`等。
   - **级联操作**：通过`cascade`参数控制删除、更新时的级联行为，防止数据孤岛或误删。
   - **联合主键与唯一约束**：如`CourseStudents`表，采用`primary_key=True`和`db.UniqueConstraint`，保证数据唯一性和完整性。

4. **实际开发中的优化与问题解决**  
   - **多对多关系的同步问题**：初期直接操作`user.enrolled_courses.append(course)`后，发现数据未及时同步到数据库。通过查阅SQLAlchemy文档，明确每次操作后需`db.session.commit()`，并在操作前后进行存在性校验，避免重复添加或删除。
   - **懒加载与性能优化**：在课程、学生数量较多时，直接`all()`查询效率低下。通过`paginate()`方法实现分页查询，结合`lazy='dynamic'`，大幅提升接口响应速度。
   - **外键约束与数据一致性**：开发过程中遇到外键约束失败、数据孤岛等问题。通过加上`nullable=False`、`ondelete='CASCADE'`等参数，确保删除父表数据时能自动清理关联数据，防止脏数据残留。
   - **联合主键与唯一索引冲突**：在多对多表设计时，初期未加唯一约束，导致学生可重复选课。后续通过`db.UniqueConstraint('course_id', 'student_id', name='uix_course_student')`解决。
   - **模型方法与数据封装**：为每个模型编写`to_dict()`方法，统一数据返回格式，便于前后端交互和接口文档维护。

5. **代码示例与结构说明**

   - **用户模型（User）部分代码：**
     ```python
     class User(db.Model):
         __tablename__ = 'users'
         user_id = db.Column(db.Integer, primary_key=True, autoincrement=True)
         username = db.Column(db.String(50), unique=True, nullable=False)
         password = db.Column(db.String(255), nullable=False)
         real_name = db.Column(db.String(50), nullable=False)
         role = db.Column(db.Enum('教师', '学生', '管理员'), nullable=False)
         email = db.Column(db.String(100))
         status = db.Column(db.Integer, default=1)
         avatar = db.Column(db.String(255), default='/avatar2.jpg')
         teaching_courses = db.relationship('Course', back_populates='teacher')
         enrolled_courses = db.relationship(
             'Course',
             secondary='course_students',
             back_populates='students',
             lazy='dynamic',
             overlaps="student,course"
         )
         # ... set_password, check_password, to_dict 等方法 ...
     ```
   - **课程与学生多对多关系（CourseStudents）：**
     ```python
     class CourseStudents(db.Model):
         __tablename__ = 'course_students'
         course_id = db.Column(db.Integer, db.ForeignKey('courses.course_id'), primary_key=True)
         student_id = db.Column(db.Integer, db.ForeignKey('users.user_id'), primary_key=True)
         join_date = db.Column(db.DateTime, default=datetime.now)
         __table_args__ = (
             db.UniqueConstraint('course_id', 'student_id', name='uix_course_student'),
         )
     ```
   - **懒加载与分页查询示例：**
     ```python
     # 查询学生已选课程并分页
     enrolled_courses = user.enrolled_courses.order_by(Course.course_name).paginate(page=1, per_page=10).items
     ```
