## 二、关键技术实现

### 1. 数据模型设计

在实际教学管理系统中，课程与学生之间是典型的多对多关系。为此，设计了中间表`course_students`，并在`User`和`Course`模型中定义了相应的关系字段。

```python
class CourseStudents(db.Model):
    __tablename__ = 'course_students'
    course_id = db.Column(db.Integer, db.ForeignKey('courses.course_id'), primary_key=True)
    student_id = db.Column(db.Integer, db.ForeignKey('users.user_id'), primary_key=True)
    join_date = db.Column(db.DateTime, default=datetime.now)
```

该中间表包含两个外键字段，course_id和student_id作为联合主键，确保每个学生只能选同一课程一次。`join_date`字段记录选课时间，为后续统计分析提供数据支持。在User模型中，通过`enrolled_courses`关系属性建立与Course模型的关联：

```python
enrolled_courses = db.relationship(
    'Course',
    secondary='course_students',
    back_populates='students',
    lazy='dynamic'
)
```

这种设计使得可以通过`secondary`参数指定中间表，实现多对多映射 ，用` user.enrolled_courses`直接访问学生所选课程，通过`back_populates`实现双向访问，便于课程和学生之间的互查。同时`lazy='dynamic'`参数优化了查询性能，支持链式查询和分页操作。

### 2. 选课功能实现

选课接口的核心在于多重校验和事务处理：

```python
@student_course_bp.route('/select', methods=['POST'])
@jwt_required()
def select_course_for_student():
    student_id = int(get_jwt_identity())
    user = User.query.get(student_id)
    if not user or user.role != '学生':
        return Result.error("用户无效或非学生", code=403)
```

首先通过JWT获取当前用户并验证学生身份，确保接口安全性。然后检查课程是否存在以及是否已选：

```python
course = Course.query.get(course_id)
if not course: 
    return Result.error("课程不存在", code=404)
if course in user.enrolled_courses: 
    return Result.error("您已选修此课程", code=400)
```

最后通过SQLAlchemy的关系管理实现选课操作：

```python
user.enrolled_courses.append(course)
db.session.commit()
```

这种实现方式充分利用了ORM的特性，使代码更加简洁易读，同时通过数据库事务保证数据一致性。

### 3. 退课功能实现

退课接口同样遵循严格的校验流程：

```python
if course not in user.enrolled_courses:
    return Result.error("您未选修此课程", code=400)
user.enrolled_courses.remove(course)
db.session.commit()
```

在确认学生确实选修该课程后，通过remove方法解除关联关系。整个操作在事务中完成，确保出现异常时能够回滚。

### 4. 课程查询优化

学生课表查询接口实现了高效的分页和搜索功能：

```python
query = user.enrolled_courses
if search_term:
    query = query.filter(Course.course_name.like(f"%{search_term}%"))
enrolled_courses = query.order_by(Course.course_name).all()
```

利用`lazy='dynamic'`的特性，可以在基础查询上灵活添加过滤和排序条件，避免加载不必要的数据，显著提升查询效率，支持按课程名模糊搜索，提升查询效率和灵活性。
