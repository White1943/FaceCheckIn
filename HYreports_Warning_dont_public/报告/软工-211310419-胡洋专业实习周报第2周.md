### 2. RSA非对称加密登录流程实现
在前后端分离的项目中，用户登录时直接传输明文密码存在安全风险。为提升安全性，本系统采用RSA非对称加密机制，前端使用公钥加密密码，后端使用私钥解密，确保密码在传输过程中的安全性。以下是核心代码片段及其分析：
1. 密钥生成与管理
系统启动时，后端动态生成一对RSA密钥对，公钥用于前端加密，私钥仅保存在后端用于解密。以下是密钥生成的实现：
```python
private_key = rsa.generate_private_key(
    public_exponent=65537,
    key_size=2048,
    backend=default_backend()
)
public_key = private_key.public_key()
```
**参数说明**
public_exponent: 公钥指数，通常为65537。
key_size: 密钥长度，设置为2048位，兼顾安全性和性能。
backend: 加密后端，使用默认后端。

通过 rsa.generate_private_key 方法生成RSA私钥，用于后续解密操作。
```python
   private_key = rsa.generate_private_key(
       public_exponent=65537,
       key_size=2048,
       backend=default_backend()
   )
   ```
   通过 private_key.public_key() 方法生成RSA公钥，供前端加密使用。
```python
   public_key = private_key.public_key()
```
2. 密码加密与解密
前端使用公钥加密密码，后端使用私钥解密。以下是密码加密与解密的实现：
```python
@auth_bp.route('/public-key', methods=['GET'])
def get_public_key():
    try:
        pem = public_key.public_bytes(
            encoding=serialization.Encoding.PEM,
            format=serialization.PublicFormat.SubjectPublicKeyInfo
        )
        pem_str = pem.decode('utf-8')
        key_str = pem_str.replace('-----BEGIN PUBLIC KEY-----\n', '')
        key_str = key_str.replace('\n-----END PUBLIC KEY-----\n', '')
        return Result.success(data={'publicKey': key_str})
    except Exception as e:
        print(f"获取公钥失败: {str(e)}")
        return Result.error("获取公钥失败")
```
**参数说明**
get_public_key: 获取公钥的接口，返回公钥字符串。
pem: 公钥的PEM格式。
pem_str: PEM格式转换为字符串。
key_str: 去除PEM格式头尾后的公钥字符串。

通过 public_key.public_bytes 方法将公钥转换为PEM格式，便于传输。
```python

```

```python

```     
将处理后的公钥字符串返回给前端，供加密使用

后端接收到前端加密的密码后，使用私钥进行解密。以下是密码解密的实现：
```python
def decrypt_password(encrypted_password, private_key):
    try:
        # Base64解码
        encrypted_bytes = base64.b64decode(encrypted_password)
        # RSA解密
        decrypted_bytes = private_key.decrypt(
            encrypted_bytes,
            asym_padding.PKCS1v15()
        )
        # 转换为字符串
        return decrypted_bytes.decode('utf-8')
    except Exception as e:
        print(f"解密失败: {str(e)}")
        return None
```
**参数说明**
encrypted_password: 前端加密的密码。
private_key: 私钥。
decrypted_bytes: 解密后的密码。

通过 base64.b64decode 方法将加密的密码进行Base64解码。使用私钥对加密字节流进行解密，得到原始密码的字节流。最后将解密后的字节流转换为字符串，供后续校验使用。

1. 用户模型设计
用户模型是系统的核心数据模型之一，定义了用户的基本信息和行为。以下是核心代码片段及其分析：
```python
class User(db.Model):
    __tablename__ = 'users'
    user_id = db.Column(db.Integer, primary_key=True, autoincrement=True)
    username = db.Column(db.String(50), unique=True, nullable=False)
    password = db.Column(db.String(255), nullable=False)
    real_name = db.Column(db.String(50), nullable=False)
    role = db.Column(db.Enum('教师', '学生', '管理员'), nullable=False)
    email = db.Column(db.String(100))
    status = db.Column(db.Integer, default=1)
    avatar = db.Column(db.String(255), default='/avatar2.jpg')
    teaching_courses = db.relationship('Course', back_populates='teacher')
    enrolled_courses = db.relationship(
        'Course',
        secondary='course_students',
        back_populates='students',
        lazy='dynamic',
        overlaps="student,course"
    )
    def set_password(self, password):
        self.password = generate_password_hash(password)
    def check_password(self, password):
        return check_password_hash(self.password, password)
    def to_dict(self):
        return {
            'username': self.username,
            'role': self.role,
            'realName': self.real_name,
            'email': self.email,
            'avatar': self.avatar
        }
```
**参数说明**
user_id为用户ID，主键，自增。username为 用户名，唯一，非空。password为 密码，非空。real_name为 真实姓名，非空。role为 角色，非空。email为 用户邮箱，可为空。status为 用户状态，默认值为1（正常）。avatar为 用户头像路径，默认值为/avatar2.jpg。teaching_courses为 教师教授的课程，关系定义。enrolled_courses为 学生选修的课程，关系定义。
set_password 方法使用 generate_password_hash 对密码进行哈希加密，check_password 方法通过 check_password_hash 验证密码是否正确。to_dict 方法将用户对象转换为字典格式，便于前端展示和接口返回。
