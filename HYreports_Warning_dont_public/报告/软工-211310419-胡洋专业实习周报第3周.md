## 二、主要代码实现与说明

### 1. 集成JWT实现用户认证

本项目采用 [Flask-JWT-Extended](https://flask-jwt-extended.readthedocs.io/) 作为认证方案。JWT（Json Web Token）是一种无状态、跨平台的认证机制，适合前后端分离项目。

在 `app.py` 中完成JWT扩展的初始化：

```python
app = Flask(__name__)
# 加载配置，包括密钥等信息
app.config.from_object('config.Config')
# 设置JWT密钥
app.config['JWT_SECRET_KEY'] = 'secret-key'  
# 设置Token过期时间
app.config['JWT_ACCESS_TOKEN_EXPIRES'] = timedelta(hours=1)
# 初始化JWT管理器
jwt = JWTManager(app)
 
```
上述代码展示了JWT扩展的完整初始化过程。我们首先创建Flask应用实例，然后从配置文件加载基础设置。接着，配置JWT密钥和令牌过期时间（这里设为1小时）并初始化JWT管理器。最后，定义了一个回调函数用于检查令牌是否已被撤销（如用户登出情况），增强了系统安全性。
### 2. 登录接口生成Token

用户登录成功后，后端生成JWT Token返回前端，前端后续请求需携带该Token。

```python
from flask_jwt_extended import create_access_token

@auth_bp.route('/login', methods=['POST'])
def login(): 
    user = User.query.filter_by(username=username).first()
    if user and user.check_password(password):
        access_token = create_access_token(identity=str(user.user_id), additional_claims={'role': user.role})
        return Result.success(data={'token': access_token, 'user': user.to_dict()}, message='登录成功')
    return Result.error("用户名或密码错误")
```
上述代码中，create_access_token 方法生成JWT令牌，并返回成功响应。项目的登录方面的实现，也结合了用户密码的加密传输，具体参考周报2.
```python

```
### 3. 受保护接口的访问控制

通过 `@jwt_required()` 装饰器保护接口，只有登录用户才能访问，实现了基于角色的权限控制，确保用户只能访问其权限范围内的资源。例如获取用户个人信息：

```python
from flask_jwt_extended import jwt_required, get_jwt_identity

@auth_bp.route('/profile', methods=['GET'])
@jwt_required()
def get_profile():
    user_id = get_jwt_identity()
    user = User.query.get(user_id)
    if not user:
        return Result.error("用户不存在")
    return Result.success(data=user.to_dict(), message='获取成功')
```

 上述代码展示了使用JWT保护的接口示例。get_profile接口获取用户个人资料，它使用@jwt_required()装饰器确保只有已登录用户可以访问。从JWT中提取用户ID后，查询并返回用户信息。
