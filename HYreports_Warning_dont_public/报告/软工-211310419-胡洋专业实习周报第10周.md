## 一、课题进展情况

本周的主要任务是"用户头像上传与个人信息管理模块的完善与优化"。头像上传和个人资料管理是提升用户体验和系统易用性的重要功能。通过本周的开发，我在`app/personal/views.py`下实现并完善了用户头像上传、头像访问、个人信息查询与修改等接口，并对文件安全、异常处理、前后端协作等方面进行了优化。

具体进展如下：

1. **头像上传接口实现与优化**  
   在`/personal/avatar`接口中，支持用户通过`multipart/form-data`方式上传头像图片。接口首先检查请求中是否包含`avatar`文件，如果没有则尝试获取第一个上传的文件，增强了前端兼容性。  
   上传时，系统会校验文件名是否为空、文件类型是否合法（仅支持JPG/PNG等常见图片格式），并使用`secure_filename`保证文件名安全，防止路径穿越攻击。  
   头像文件会被保存到`static/images/avatars/`目录下，文件名采用`avatar_用户ID_时间戳.扩展名`的格式，确保唯一性和可追溯性。例如：

   ```python
   new_filename = f'avatar_{user_id}_{int(time.time())}.{ext}'
   file_path = os.path.join(avatar_dir, new_filename)
   ```

   上传新头像时，系统会自动删除用户的旧头像文件，避免服务器存储冗余和垃圾文件。

2. **头像访问接口设计**  
   通过`/personal/avatar/<filename>`接口，前端可以直接访问用户头像图片。接口会根据文件扩展名自动设置`Content-Type`，确保图片在浏览器端正常显示。例如，JPG图片会返回`image/jpeg`，PNG图片会返回`image/png`。  
   如果请求的头像文件不存在，接口会返回404错误和友好的提示信息。

3. **个人信息查询与修改**  
   - 通过`/personal/info`的GET方法，用户可以获取自己的用户名、角色、真实姓名、邮箱和头像地址等信息，便于前端展示和个人中心页面的数据填充。
   - 通过`/personal/info`的PUT方法，用户可以修改自己的真实姓名和邮箱。接口会校验用户身份，确保只有本人可以修改自己的信息，修改后会返回最新的个人资料数据。

4. **安全性与异常处理**  
   - 所有涉及用户数据的接口均加上了`@jwt_required()`装饰器，确保只有登录用户才能访问和修改自己的信息。
   - 对于头像上传，系统会校验文件类型、文件名、用户身份等，任何异常都会返回明确的错误信息，并在后端日志中记录详细错误，便于后期排查。
   - 数据库操作采用事务机制，出现异常时自动回滚，保证数据一致性。

5. **前后端协作与体验优化**  
   - 前端上传头像时，只需将图片文件以`avatar`字段上传即可，接口会自动处理文件名和存储路径，返回新的头像URL，前端可直接用于展示。
   - 个人信息修改接口返回最新的用户数据，前端可实时刷新页面内容，提升用户体验。
   - 头像上传和个人信息修改均有详细的错误提示，便于用户理解和操作。

## 二、主要实现细节与说明

- **文件类型校验与安全处理**  
  头像上传接口通过如下方式校验文件类型，确保只允许安全的图片格式：

  ```python
  ALLOWED_EXTENSIONS = {'png', 'jpg', 'jpeg', 'PNG', 'JPG', 'JPEG'}
  def allowed_file(filename):
      return '.' in filename and filename.rsplit('.', 1)[1].upper() in ALLOWED_EXTENSIONS
  ```

  这样可以有效防止用户上传可执行文件或恶意脚本，提升系统安全性。

- **头像文件的唯一命名与存储**  
  文件名采用用户ID和时间戳拼接，保证每次上传的头像文件唯一，避免文件覆盖和命名冲突。同时，所有头像文件统一存储在`static/images/avatars/`目录下，便于管理和备份。

- **旧头像自动清理**  
  上传新头像时，系统会自动检测并删除用户的旧头像文件，避免服务器空间浪费。例如：

  ```python
  if user.avatar:
      old_avatar_path = os.path.join(current_app.root_path, 'static', user.avatar.lstrip('/'))
      if os.path.exists(old_avatar_path):
          os.remove(old_avatar_path)
  ```

- **接口返回与前端集成**  
  上传成功后，接口会返回新的头像URL，前端可直接使用该URL展示用户头像，无需额外处理。个人信息修改接口也会返回最新的用户数据，便于前端同步更新。
